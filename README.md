Python Projects

A collection of Python projects I build to practise and sharpen my programming skills, from small console programs to automation and AI-related tools. Each project lives in its own folder and can be run on its own.

1. Password Generator

Generates a random password based on the number of letters, symbols and digits the user chooses.

Concepts practised:

Variables and input() with type conversion (int())
Lists of characters
for loops with range()
random module (choice, shuffle)
Joining a list into a string with "".join()
2. Hangman

Word guessing game where the player has 6 lives to find a hidden word.

Concepts practised:

Lists and indexing (word[position], display[position])
for and while loops
Conditions (if / else) and the in operator
String methods (.lower(), " ".join())
Splitting a program into modules (words.py, art.py) and importing them
3. Caesar Cipher

Encrypts and decrypts messages using a Caesar shift.

Concepts practised:

Functions with parameters and keyword arguments
String indexing and looping over characters
Modulo operator (%) to wrap around the alphabet
while loop to repeat the program
Input validation for invalid choices and numbers
4. Secret Auction

Blind auction program that finds the highest bidder.

Concepts practised:

Dictionaries (adding and reading key-value pairs)
Looping over a dictionary
Functions
Input validation for bids and yes/no answers
5. Blackjack

Console Blackjack game against the computer.

Concepts practised:

Functions and return values
Lists and list methods (append, remove)
Conditionals and game logic (scoring, Ace handling, win/lose rules)
Game loops with boolean flags
random module (choice)
6. Number Guessing Game

Guess a random number between 1 and 100 with limited attempts and difficulty levels.

Concepts practised:

Functions and return values
Constants for fixed values
Variable scope (local vs global)
while loop with a counter
random.randint()
Input validation (isdigit(), number range)
7. Higher Lower Game

Guess which of two countries has the higher population and build a streak.

Concepts practised:

List of dictionaries as a small dataset
Reading dictionary values
random.shuffle() and list.pop() so no item repeats
Modules (art.py, data.py) and imports
Docstrings and a main() function with if __name__ == "__main__"
Tracking a high score across games

More projects are added regularly.

Running a project

Each project lives in its own folder. To run one:

bash
cd project-folder
python main.py

Requires Python 3.
